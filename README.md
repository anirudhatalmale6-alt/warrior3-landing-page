# Landing Page

A single self-contained HTML page. No images, no scripts, no external files —
the background and all the effects are pure CSS, so it works anywhere you
upload it.

## Use it

Upload `index.html` to your web host. That's it.

## Editing

Everything you need to change is marked with a comment block inside the file:

- **Page title** — near the top, in the `<title>` tag.
- **Your banner** — the `banner-card` box. Drop your banner image in there.
- **Your text ads** — the `cards` block. To add another ad box, copy the
  section marked `COPY FROM HERE` / `COPY TO HERE` and paste it in.

Ad boxes sit two per row and flow onto new rows automatically. If you end up
with an odd number, the last one centres itself. On phones they stack into a
single column.
